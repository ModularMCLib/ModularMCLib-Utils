# ModularMCLib Utils

面向 Minecraft 26.1.2、NeoForge 26.1.2.126 与 Java 25 的通用工具库。模组标识为 `mmclutils`。

## 安装与构建

将发布的完整 JAR 放入客户端或专用服的 `mods` 目录。

在仓库根目录运行 Gradle Wrapper，产物位于 `build/libs/`。

```powershell
.\gradlew.bat build
```
